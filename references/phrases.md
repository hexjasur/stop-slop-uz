# Iboralar ro'yxati (o'zbekcha)

Har bir element uchun: nima bo'lishi, nima bilan almashtirish mumkinligi.

## Kirish gaplari

| Ibora | Muammo | Tuzatish |
|-------|--------|----------|
| Shuni alohida ta'kidlash joizki, | Hech narsa qo'shmaydi | Gapni to'g'ridan-to'g'ri boshlang |
| Shuni aytish kerakki, | Hech narsa qo'shmaydi | O'chiring |
| Bugungi kunda | Vaqt belgisi hech narsa aytmaydi | Aniq yil, sana yoki o'zgarish nomi |
| Ushbu maqolada biz ko'rib chiqamiz | Meta-gap, mavzuning o'zi aytilsin | O'chiring, birinchi haqiqiy gapdan boshlang |
| Keling, ... ko'rib chiqaylik | Qo'llanmada bir marta mumkin | Qadamni yozing: "1. ... ni oching" |

## Xulosa gaplari

| Ibora | Tuzatish |
|-------|----------|
| Xulosa qilib aytganda, | Oxirgi gap sifatida ortiqcha. O'chiring yoki faktni yozing |
| Demak, shuni ko'ramizki, | O'chiring |
| Shu tariqa | O'chiring |

## Ortiqcha bog'lovchilar

| Ibora | Tuzatish |
|-------|----------|
| shuningdek | Vergul yoki yangi gap. Ko'pincha o'chiriladi |
| bundan tashqari | Agar yangi fakt bo'lsa, o'z gapi bilan yozing |
| o'z navbatida | O'chiring |
| shu bilan birga | Ko'pincha o'chiriladi |
| shu o'rinda | O'chiring |
| muhim jihati shundaki | O'chiring, faktni yozing |
| bu shuni anglatadiki | O'chiring yoki sababni yozing |

## Noaniq baholash so'zlari

| So'z | Almashtirish usuli |
|------|--------------------|
| samarali | Natijani raqamda yozing: "Yuklash vaqti 4 sekunddan 1,2 sekundga tushdi" |
| innovatsion | Nima yangi ekanini yozing |
| dolzarb | Nima uchun hozir muhimligini yozing yoki o'chiring |
| har tomonlama | Qaysi jihatlar ekanini sanab bering |
| turli xil | Aniq turlarni yozing |
| ko'plab | Raqam yoki aniq ulush yozing |
| katta ahamiyatga ega | Nima uchun ahamiyatli ekanini yozing |
| muhim rol o'ynaydi | Nima qilishini yozing |
| keng imkoniyatlar | Qanday imkoniyat ekanini yozing |

## Kuchaytiruvchi so'zlar

Quyidagilar faqat haqiqatda shunday bo'lsa qolsin. Aks holda o'chiring:

- hammasi, barchasi
- butunlay, mutlaqo
- doimo, hech qachon
- aynan, albatta, shubhasiz
- aslida, haqiqatan
- juda, eng

## Tarjima uslubidagi iboralar

| Ibora | Tuzatish |
|-------|----------|
| amalga oshirmoq | qilmoq, bajarmoq, o'tkazmoq (kontekstga qarab) |
| e'tibor qaratmoq | e'tiborni tortadi yoki aniq fe'l |

| ... sifatida namoyon bo'ladi | "... bo'ladi" yoki aniq fe'l |
| ... bilan bog'liq holda | Aniq bog'liqlikni yozing |
| ushbu | bu |
| mazkur | bu |
| ...ni taqdim etmoq | ...ni ko'rsatmoq, berish |

## Yumshatish (hedging)

Faqat haqiqiy noaniqlik bo'lsa, bir marta yozing:

- balki, ehtimol, go'yo, deyarli

Agar bir matnda bir nechta yumshatish bo'lsa, ularni bitta gapga jamlang yoki o'chiring.

## To'ldiruvchi iboralar

- tabiiyki
- ayni paytda
- o'z-o'zidan ravshanki
- shu bilan birga

## Tekshirish usuli

Matnni skanerlang. Har bir topilgan so'z uchun uchtadan birini tanlang:
1. O'chirish
2. Aniq raqam, nom yoki misol bilan almashtirish
3. Saqlash va sababini yozish
